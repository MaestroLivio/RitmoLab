RITMOLAB 1.2 — INSTALLAZIONE

Scarica il file adatto da:
https://github.com/MaestroLivio/RitmoLab/releases/latest

Windows 10/11 x64
  Apri RitmoLab-<versione>-Windows-x64.exe e segui le indicazioni.
  L'installer non è firmato commercialmente. Se SmartScreen chiede conferma,
  verifica che il file venga dal repository ufficiale.

macOS 12 o successivo, Apple Silicon (serie M)
  Apri RitmoLab-<versione>-macOS-arm64.dmg e trascina RitmoLab in Applicazioni.
  L'app è firmata ad hoc, non notarizzata. Dopo aver verificato la provenienza,
  se macOS blocca l'apertura, usa Impostazioni di Sistema > Privacy e sicurezza
  > Apri comunque, quando questa opzione è disponibile.

Per usare l'app e i suoni non occorre una connessione. Il microfono è richiesto
solo in modalità Canto; la tastiera del computer funziona senza microfono.
Se usi la base con il microfono, indossa le cuffie.

Dalla versione 1.2 non vengono più prodotti pacchetti per Linux, ChromeOS,
Mac Intel e Windows portable, né una versione HTML autonoma.
